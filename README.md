# LLM-based Counselling Process using Cognitive Behavioural Therapy (CBT)
Deep Learning project - Anubrata (106123011) & Tarun (106123101)

## 1. Problem
Students often have no immediate access to a counsellor. We build a CBT-guided chatbot that
(a) detects the user's **cognitive distortion**, (b) walks through the **CBT thought-record stages**,
and (c) replies with **Socratic questions** generated by a fine-tuned LLM, with a **safety layer** for crises.

## 2. Architecture
```
User message
   |
   v
[Safety layer: regex crisis detection] --yes--> Tele-MANAS 14416 / 112 message (LLM never called)
   |no
   v
[Module 1: DistilBERT cognitive-distortion classifier (12 classes)]
   |
   v
[CBT stage tracker: Check-in -> Situation/Thought/Emotion -> Name pattern -> Socratic challenge -> Balanced thought -> Action plan]
   |
   v
[Module 2: Qwen2.5-0.5B-Instruct + LoRA fine-tuned on CBT dialogues]  (rule-based fallback if no GPU/weights)
   |
   v
[Output guard: no diagnosis / medication / too-short replies] --> reply
```

## 3. Setup and run order
```bash
pip install -r requirements.txt
python -m src.make_dataset                 # builds data/*.jsonl  (synthetic seed data)
python -m src.distortion_model --baseline  # TF-IDF + LogReg baseline
python -m src.distortion_model --train     # fine-tune DistilBERT  (results/training_curve.png)
python -m src.train_generator --epochs 2   # LoRA fine-tune Qwen    (use a GPU / Colab T4)
python -m src.evaluate                     # metrics.json, confusion_matrix.png
python -m src.cbt_engine                   # chat in terminal
python app.py                              # web UI
```
Everything works without step 3-4 too (falls back to baseline + rule-based replies), so you can demo at any time.

## 4. Datasets (IMPORTANT - replace the synthetic seed for your final numbers)
`make_dataset.py` creates a template-based seed set so the pipeline runs end to end. The test split uses
**templates not seen in training**, so scores are honest and lower than random-split scores.
For the final report, add real data and re-run:
- Cognitive-distortion annotated data (e.g. "Therapist Q&A" distortion dataset by Shreevastava & Foltz, 2021) - map its labels to `src/config.py`.
- Counselling conversations on Hugging Face, e.g. `Amod/mental_health_counseling_conversations` - convert to the same
  `{user, distortion, assistant}` format as `data/cbt_dialogues.jsonl`.
Cite whichever you use and check its licence.

Seed-data result I measured (TF-IDF baseline, held-out templates): accuracy 0.42, macro-F1 0.37.
This is the number your DistilBERT should beat - run it yourself and report your own figures.

## 5. Evaluation (what to put in the report)
- Classifier: accuracy, macro-F1, per-class report, confusion matrix, DistilBERT vs TF-IDF baseline.
- Training curves (`results/training_curve.png`, `results/generator_loss.png`).
- Safety layer: crisis recall and false-positive rate (`evaluate.py`).
- Response quality: guardrail pass-rates, plus a small **human rating** (5 classmates rate 20 replies 1-5 on empathy,
  helpfulness, CBT-adherence). Also compare prompted-only vs LoRA-fine-tuned model.

## 6. Ethics and limitations (write this section - examiners like it)
- Not a therapist; not for diagnosis; disclaimer shown in UI.
- Regex safety is a first line only; it can miss indirect expressions of crisis. A trained risk classifier is future work.
- Synthetic data has low linguistic diversity; real data is needed for generalisation.
- Small LLM can hallucinate or be generic; the output guard reduces but does not remove this.
- No chat data is stored. Mention privacy.

## Guided conversation flow (updated)

The exploration now follows a fixed sequence of 10 distinct questions: situation,
automatic thought, emotion, impact, supporting evidence, alternative evidence,
balanced thought, coping response, strengths/support, and one practical next step.
The question sequence is controlled by the application so repeated LLM questions
cannot trap the conversation in the same stage. The final reflection uses excerpts
from the user's actual messages and the classifier output as a non-clinical suggestion.
